Game development

Pelajari cara membuat game yang menarik dan interaktif dengan memahami dasar-dasar desain, gameplay, serta pemrograman.

Hubungi Kami

Profesi

Game Developer

membuat sistem dan mekanik game menggunakan bahasa pemrograman.

3D Modeler

membuat model 3D untuk karakter, bangunan, senjata, dan objek.

VFX Artist

membuat efek visual seperti ledakan, api, asap, sihir, dan efek skill.

Game Designer

mmerancang gameplay, aturan, level, mekanik, dan pengalaman pemain.

Level Designer

merancang map, level, rintangan, dan penempatan objek dalam game.

Game Writer

membuat cerita, dialog, karakter, dan alur narasi.

Game Producer

mengatur proyek, jadwal, tim, dan proses pengembangan game.

Game UI/UX Designer

merancang menu, HUD, tombol, inventori, dan pengalaman pengguna.

Skill yang dibutuhkan

Programming

Memahami bahasa pemrograman untuk membuat sistem dan mekanik game.

Game Engine

Mampu menggunakan game engine seperti Unity, Unreal Engine, atau Godot.

Game Design

Merancang gameplay, mekanik, level, dan pengalaman pemain.

Problem Solving

Mampu menemukan masalah dan mencari solusi dalam proses pengembangan game.

3D/2D Art

membuat atau mengolah karakter, lingkungan, objek, dan aset game.

Creative Thinking

menghasilkan ide gameplay, karakter, dunia, dan fitur yang menarik.
